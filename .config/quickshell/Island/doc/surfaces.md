    HomeClock & Strip

        Поведение: Два взаимозаменяемых мини-виджета, служащих отправной точкой. Strip — минималистичная полоска (режим фокуса/полноэкранный), HomeClock — цифровые часы.

        Связи: Нажатие на Strip открывает HomeClock. Нажатие на HomeClock вызывает поверхность основной панели (bar).

BatteryProfileSurface (оборачивает модуль Battery)

    Поведение: Панель управления питанием. Показывает точный заряд батареи. При подключении зарядки полоска заряда начинает пульсирующую анимацию (от 0 до 100%), а цвет меняется на акцентный.

    Взаимодействие: Содержит три ProfileButton, которые через общую инстанцию BatteryService управляют режимом энергосбережения powerprofilesctl. Нажатие на иконку меняет физический профиль системы.

CalendarSurface (оборачивает модуль Calendar)

    Поведение: Предоставляет интерактивный виджет календаря сеткой 7x6. Поддерживает навигацию по месяцам с анимацией затухания.

    Взаимодействие: Текущий день автоматически подсвечивается. Прошедшие дни отображаются с пониженной прозрачностью (0.5). Пользователь может кликнуть на активный день в месяце, чтобы визуально "выбрать" его (сохраняется в selectedDateKey). При смене месяца выбор сбрасывается.

EyeReminder Surface

    Поведение: Всплывающий оверлей для отдыха глаз. Перекрывает фокус на заданное в Configs.eyeSurfaceDuration время (10 секунд).

    Взаимодействие: Не требует действий пользователя. Закрывается сам по истечении таймера, испуская сигнал backRequested для роутера.

Bar (Основная панель)

    Слой: Компоновщик (Layout Manager).

    Описание: Основной "остров" (Dynamic Island), который раскрывается по центру экрана или сверху. Является контейнером для трех логических блоков: Workspaces (левая часть), Clock (центр) и RightActions (правая часть).

    Взаимодействие: Сам по себе Bar не содержит бизнес-логики. Он служит "маршрутизатором" (Event Router), собирая сигналы surfaceRequested и closeRequested от своих дочерних элементов и передавая их наверх (в SurfaceHost или Window), чтобы открыть нужный виджет (например, календарь или панель батареи).

Внутренние компоненты Bar:

    Clock: Двухстрочный виджет времени и даты. Выступает триггером для вызова CalendarSurface.

    RightActions: Контейнер типа Row, объединяющий системные кнопки (Icon). Инкапсулирует вызовы к EyeReminderService, PomodoroService, PowerService и запросы на открытие дополнительных панелей (Settings, Battery).

AppLauncher Surface

    Поведение: Всплывающее окно типа Spotlight/Rofi. Состоит из строки поиска (SearchBar) и выпадающего списка (AppList).

    Взаимодействие: При появлении окна фокус автоматически перехватывается строкой поиска.

        Ввод текста фильтрует ListModel в реальном времени.

        Стрелки Вверх/Вниз в текстовом поле не двигают курсор, а перехватываются и меняют currentIndex списка (перемещая выделение).

        Enter запускает выделенное приложение.

        Escape при наличии текста очищает поле. При пустом поле — закрывает окно.

    Анимации: Список имеет динамическую высоту (implicitHeight привязана к contentHeight списка, но не больше maxHeight). При фильтрации окно плавно "сжимается" или "расширяется" вверх-вниз в зависимости от количества найденных программ.
