WorkspaceService.qml

    Слой: Интеграция с системой (Hyprland).

    Описание: Отвечает за получение состояний рабочих столов (активность, наличие открытых окон) и управление ими.

    Ключевые методы: >     * isOccupied(id): Проверяет наличие топлевел-окон на конкретном воркспейсе.

        activateWorkspace(id): Переключает фокус на выбранный воркспейс через нативный биндинг Hyprland.dispatch("workspace", id).

BatteryService.qml

    Слой: Системный мониторинг и управление питанием (Arch/Linux).

    Описание: Предоставляет реактивные данные о заряде батареи и статусе зарядки. Управляет профилями производительности системы через powerprofilesctl.

    Как работает: Использует Quickshell.Io.Process с цикличным sh-скриптом (каждые 3 секунды) для чтения данных напрямую из /sys/class/power_supply/BAT*. Это позволяет обойтись без дополнительных D-Bus или UPower демонов.

    Ключевые свойства/методы: >     * percent, isCharging, activeProfile.

        setProfile(profileName): Асинхронно устанавливает системный профиль (eco, balanced, performance).

CalendarService.qml

    Слой: Логика вычисления дат.

    Описание: Содержит набор утилит для работы с системным временем и календарем. Отвечает за локализацию названий месяцев и проверку состояний конкретной даты.

    Ключевые методы/свойства: >     * today: Текущая дата (Date object).

        isToday(y, m, d), isPast(y, m, d): Булевы проверки статуса дня.

        dayKey(y, m, d): Генерирует уникальный строковый ключ для идентификации выбранного дня (например, "2026-07-31").

EyeReminderService.qml & PomodoroService.qml

    Слой: Локальные пользовательские таймеры.

    Описание: Singleton-сервисы, реализующие логику контроля времени. Не создают и не удаляют объекты в памяти на лету (используется декларативный Timer с привязкой свойства running), что гарантирует нулевые утечки памяти при постоянном включении/выключении.

    PomodoroService имеет встроенную интеграцию с Linux D-Bus нотификациями (через notify-send), обеспечивая системное уведомление о сменах циклов.

AppService.qml

    Слой: Системный парсер и провайдер данных.

    Описание: При инициализации (Component.onCompleted) запускает shell-скрипт через Quickshell.Io.Process, который сканирует /usr/share/applications и ~/.local/share/applications. Скрипт извлекает Name, Icon и Exec, игнорируя скрытые приложения (NoDisplay=true).

    Оптимизация: Данные парсятся через потоковый SplitParser, по мере чтения сразу добавляясь в реактивный ListModel filteredApps. При поиске модель обновляется "умно" (через .move(), .insert(), .remove()), что позволяет QML-движку анимировать элементы, а не перерисовывать весь список с нуля. Управляет запуском приложений через системный Shell.

AudioService.qml & BrightnessService.qml

        Слой: Системные обертки (Инстанцируемые).

        Архитектура: Сервисы не являются синглтонами. Они привязывают свою работу к свойству active вызывающего UI-компонента. При active = true сервис выполняет однократный запрос текущего состояния (через wpctl / brightnessctl) и активирует легковесную подписку на системные события ядра (udevadm monitor для подсветки, pactl subscribe для звука).

        Производительность: Потребление CPU равно 0%, так как удален метод поллинга по таймеру. Когда UI-панель закрывается (или уничтожается), сервисы останавливают системные процессы и освобождают память.
